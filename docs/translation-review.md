# English instrument review — 17 September 2026

All 144 English texts were read alongside the German original during this release preparation. The review checked actions, actors, omissions, negations, modality, evaluative intensity and cultural references. IDs and order are identical. This is a Codex-assisted editorial review, not independent human validation or an empirical equivalence study.

Two corrections were made to the existing Explorer translation:

| ID | Previous wording | Released wording | Reason |
|---|---|---|---|
| B2_v76_2 | only fact checking | only testing factual recall | “Faktenabfrage” tests remembered facts; it does not verify claims. |
| H_v125_2 | That's still future music. | That's still a thing of the future. | Translate the idiom “Zukunftsmusik” by meaning. |

The remaining 142 translations were retained. English “student” is grammatically gender-neutral where German uses gendered nouns; existing gendered pronouns remain. No cultural adaptation was introduced. “Education”, learning, autonomy, inclusion, democracy and ecological intrinsic value retain their context-specific formulations.

German remains the original measurement condition. English runs have their own language, prompt and instrument hash. An English replication is a language extension, not evidence that the two versions yield equivalent measurements.
